# Nicker Horse Data

Version 1.0.0 brings together six compilations on equine equipment, hoof and leg health, care costs, research, search interest, and ChatGPT answers.

| Dataset | Folder | Project page |
| --- | --- | --- |
| Nicker Horse Red Light Spec Index 2026 | [D1-spec-index/](D1-spec-index/) | [Data page](https://nickerhorse.com/pages/horse-red-light-device-spec-index-2026) |
| Nicker Hoof & Leg Problem Stats 2026 | [D2-hoof-leg-stats/](D2-hoof-leg-stats/) | [Data page](https://nickerhorse.com/pages/horse-hoof-and-leg-health-statistics) |
| Nicker US Hoof Care Cost 2026 | [D3-hoof-care-cost/](D3-hoof-care-cost/) | [Data page](https://nickerhorse.com/pages/cost-of-horse-leg-and-hoof-care-per-year) |
| Nicker Equine Light Therapy Evidence Map 2026 | [D4-evidence-map/](D4-evidence-map/) | [Data page](https://nickerhorse.com/pages/equine-light-therapy-evidence-map-2026) |
| Nicker Hoof Problem Seasonality Index 2026 | [V5-hoof-seasonality/](V5-hoof-seasonality/) | [Data page](https://nickerhorse.com/pages/horse-hoof-and-leg-health-statistics) |
| Nicker AI Answer Audit 2026 | [A06-ai-answer-audit/](A06-ai-answer-audit/) | [Data page](https://nickerhorse.com/pages/what-ai-tells-horse-owners-about-red-light-therapy) |

Each folder provides a schema, collection notes, citations, and SHA-256 digests. The CSV files use comma delimiters and UTF-8 encoding without a BOM. The Nicker compilations use CC BY 4.0 with attribution and source notes in each folder.
