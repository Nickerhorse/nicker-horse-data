# Methods for Hoof Problem Seasonality Index

Group the source observations by calendar month. The calculation assigns 0.5 to source values below one and rounds each calendar-month average divided by the full-series average times 100. Mark a series as sparse when more than one fifth of observations are zero. The separate state extract scales query share to the top reported state at 100 and keeps omitted geography scores blank.

## Interpretation

The full monthly extract includes a partial November 2026. Use the series status column to filter sparse terms before describing a seasonal pattern. There are 47 reported state scores and four blank geography rows. The heat map uses the six indexed terms with sufficient data.
