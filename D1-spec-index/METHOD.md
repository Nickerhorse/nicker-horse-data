# Methods for Horse Red Light Spec Index

Build the comparison group from the rival LED products. Exclude the publisher reference record N00 and the non-LED entries R29 and R30 from that denominator. For individual USD prices, restrict the analysis to eligible single boots, wraps, sleeves, or bell boots and keep bundle amounts separate. Record the conditions stated with an irradiance figure before comparing disclosures. The underlying listings were checked November 17–25, 2026.

## Interpretation

Keep each USD amount attached to the listed package size and date. Some values are reported as sale amounts. The earlier graphics have their own time frame and denominator. The index describes disclosures made by selected seller pages. The recorded technical values depend on the measurement contexts reported on those pages.
